# new-year-gift

Интерактивный новогодний веб-проект, который воспроизводит фоновую музыку и в полночь (00:00) автоматически перенаправляет пользователя на праздничную трансляцию .

## Описание проекта

Этот проект представляет собой развлекательный веб-сайт с элементом сюрприза. Скрипт отслеживает системное время пользователя. Пока до полуночи остается время, на странице воспроизводится фоновая музыка. Как только часы показывают 00:00, происходит автоматическое перенаправление на страницу с видеопоздравлением . Проект демонстрирует навыки работы с объектом `Date` в JavaScript и управлением медиаэлементами.

---

## Стек технологий

- **HTML5** — разметка страницы и медиаэлементов
- **CSS3** — базовая стилизация интерфейса
- **JavaScript (ES6+)** — логика отслеживания времени, управление аудио и автоматическое перенаправление (redirect)

## Запуск локально

Проект является полностью статическим и не требует установки зависимостей.

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Kievsky332/new-year-gift.git
   ```
2. Перейдите в папку проекта:
   ```bash
   cd new-year-gift
   ```
3. Откройте файл index.html двойным кликом в любом современном браузере.
>[!TIP]
>  Для проверки срабатывания таймера в 00:00 можно временно изменить условие в файле main.js на текущее время.

# Структура проекта

```text
new-year-gift/
 ├── index.html       # Главная страница с таймером и фоновой музыкой
```
